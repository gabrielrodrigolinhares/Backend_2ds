# Levantamento de Requisitos e Planejamento Web

## 🎨 Especificações Visuais e Estruturais Gerais
*   **Paleta de Cores:**
    *   **Primária:** Roxo (Acessibilidade para botões de destaque, links ativos e elementos principais)
    *   **Secundária:** Verde (Destaques secundários, badges e botões de chamada para ação alternativa)
    *   **Fundo:** Branco (Garante alto contraste e limpeza visual)
    *   **Texto:** Azul Claro (Utilizado estrategicamente para manter a harmonia, garantindo o contraste necessário contra o fundo branco)
*   **Navegação (Cabeçalho Fixo):**
    *   Fixo no topo (`position: sticky` ou `fixed`).
    *   Links estruturados para: `/` (Home), `/produtos`, `/sobre` e `/contato`.
    *   Design responsivo (Menu hambúrguer em telas menores via Flexbox).
*   **Rodapé Global:**
    *   Texto de Direitos Autorais (Copyright).
    *   Links para Redes Sociais Fictícias (Ícones estruturados com Grid/Flexbox).
